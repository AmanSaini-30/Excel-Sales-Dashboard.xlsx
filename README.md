 # 📊 Excel Sales Analytics Dashboard

## 📌 Project Overview

This project is an interactive Excel dashboard designed to analyze
sales performance and provide meaningful business insights.

The dashboard summarizes key performance indicators (KPIs), sales
trends, and other important business metrics in an easy-to-understand
visual format.

## 🛠️ Tools & Technologies

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Formulas
- KPI Analysis
- Data Cleaning
- Data Visualization
- Interactive Dashboard

## 📂 Workbook Structure

The workbook contains the following sheets:

- Main Data
- Dashboard Data
- Data Check
- KPIS
- Dashboard Creation

## 📊 Key Features

- Interactive sales dashboard
- KPI tracking
- Sales performance analysis
- Data validation and checking
- Visual charts and graphs
- Business performance insights

## 📈 Key KPIs

The dashboard focuses on important business performance indicators
such as sales performance, trends, and other calculated metrics.

## 🎯 Project Objective

The main objective of this project is to transform raw business data
into an interactive and visually appealing dashboard that can help
stakeholders understand performance and make data-driven decisions.
